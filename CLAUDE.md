# CLAUDE.md — regras desta conversa (site vinicavalcanti.com)

## Escopo: este chat é só do site
Este repositório é o site estático vinicavalcanti.com (home, LPs de cursos, LP da mentoria). Tudo que for do site é escopo normal: páginas, copy, design, ícones, i18n EN/PT, SEO, favicon, analytics, deploy no GitHub Pages, links da Hotmart, banner do Discord, documentação AI-STUDIO.md e o aviso à sessão de stories sobre trabalho publicado no site.

## Proteção: pedido fora do site exige confirmação
O Vini tem outros chats (por exemplo, o dos stories do Instagram) e às vezes manda o pedido no chat errado. Se um pedido NÃO for sobre o site (stories, posts, reels, vídeos, artes avulsas, GIFs, e-mails, textos para redes sociais, outros projetos ou qualquer coisa fora deste repositório):

1. NÃO comece o trabalho.
2. Pergunte antes, em uma frase, se ele tem certeza de que é para este chat. Exemplo: "Esse pedido parece ser de outro chat (stories?). Tem certeza que quer fazer aqui no chat do site?"
3. Só prossiga depois de uma confirmação explícita dele.

Em caso de dúvida se é do site ou não, pergunte também. A pergunta custa uma linha; o trabalho errado custa tempo.

## Regras já vigentes (resumo; detalhes em cada AI-STUDIO.md)
- Ler o AI-STUDIO.md da página antes de editar e seguir o que está lá.
- Nunca alterar tokens de design, links da Hotmart ou arquivos .mp4 sem autorização.
- Toda edição de copy precisa ser espelhada no `js/i18n.js` da página (EN + PT), senão o toggle apaga a edição.
- Sem travessões e sem "firulas de IA" no copy. Sem urgência falsa; promoções reais podem.
- Commits direto na `main` (autorizado), sempre conferindo `git branch --show-current` antes de commitar e fazendo push ao final.
